# 資料庫初始化指南

## 前置條件

1. ✅ 已安裝 PostgreSQL (Docker 或本機)
2. ✅ 已建立資料庫 `metora`
3. ✅ 已設定 `.env` 檔案中的資料庫連線資訊

## 初始化步驟

### 方案一: 全新初始化 (推薦)

如果這是第一次初始化資料庫,請按照以下步驟執行:

```bash
# 1. 切換到 backend 目錄
cd backend

# 2. 檢查 alembic 配置是否正確
alembic current

# 3. 執行所有遷移腳本 (建立表結構)
alembic upgrade head

# 4. 初始化基礎資料 (管理員帳號、角色)
python scripts/init_database.py
```

### 方案二: 資料庫狀態異常時重置

如果之前已經執行過遷移但狀態不一致,可以重置資料庫:

```bash
cd backend

# 1. 回滾所有遷移 (刪除所有表)
alembic downgrade base

# 2. 重新執行遷移
alembic upgrade head

# 3. 重新初始化基礎資料
python scripts/init_database.py
```

### 方案三: 直接使用 SQL 重置 (最徹底)

如果遇到無法解決的問題,可以手動清空資料庫:

```bash
# 連線到 PostgreSQL
psql -h 127.0.0.1 -p 5432 -U metora -d metora

# 在 psql 中執行
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
GRANT ALL ON SCHEMA public TO metora;
GRANT ALL ON SCHEMA public TO public;
\q

# 然後執行遷移
cd backend
alembic upgrade head
python scripts/init_database.py
```

## 驗證初始化結果

### 1. 檢查表結構

```bash
psql -h 127.0.0.1 -p 5432 -U metora -d metora -c "\dt"
```

應該看到以下表:
- ✅ `users` - 使用者表
- ✅ `roles` - 角色表
- ✅ `user_roles` - 使用者-角色關聯表
- ✅ `refresh_tokens` - Refresh Token 表
- ✅ `collections` - 集合表
- ✅ `datasets` - 資料集表
- ✅ `alembic_version` - Alembic 版本追蹤表

### 2. 檢查初始資料

```bash
# 檢查管理員帳號
psql -h 127.0.0.1 -p 5432 -U metora -d metora -c \
  "SELECT id, username, email, is_active FROM users;"

# 檢查角色
psql -h 127.0.0.1 -p 5432 -U metora -d metora -c \
  "SELECT id, name, description FROM roles;"
```

### 3. 測試登入

啟動後端服務並測試登入:

```bash
# 啟動後端 (在專案根目錄)
cd ..
python backend/run.py

# 在另一個終端測試登入
curl -X POST http://localhost:8002/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "admin123"}'
```

## 常見問題

### Q1: `alembic current` 顯示 "No current revision"

這是正常的,表示還沒有執行過任何遷移。請執行 `alembic upgrade head`。

### Q2: 遷移時出現 "Target database is not up to date"

執行以下指令同步資料庫狀態:

```bash
alembic stamp head
```

### Q3: `init_database.py` 報錯 "角色已存在"

這表示基礎資料已經初始化過了,可以忽略此錯誤。或者重新執行方案二重置資料庫。

### Q4: 連線資料庫失敗

1. 確認 Docker 容器是否正在運行
2. 檢查 `.env` 中的資料庫連線資訊是否正確
3. 確認資料庫使用者 `metora` 有正確的權限

```bash
# 測試連線
psql -h 127.0.0.1 -p 5432 -U metora -d metora -c "SELECT 1;"
```

## Alembic 常用指令

```bash
# 查看當前版本
alembic current

# 查看遷移歷史
alembic history --verbose

# 升級到最新版本
alembic upgrade head

# 升級一個版本
alembic upgrade +1

# 回滾一個版本
alembic downgrade -1

# 回滾到初始狀態 (清空所有表)
alembic downgrade base

# 生成新的遷移腳本 (修改模型後)
alembic revision --autogenerate -m "描述"

# 手動標記版本 (不執行遷移)
alembic stamp head
```

## 新增資料庫模型後的流程

當您新增或修改 ORM 模型後:

```bash
# 1. 生成遷移腳本
alembic revision --autogenerate -m "add new_table"

# 2. 檢查生成的腳本 (在 alembic/versions/ 目錄)
# 確認變更符合預期

# 3. 執行遷移
alembic upgrade head

# 4. 驗證資料庫結構
psql -h 127.0.0.1 -p 5432 -U metora -d metora -c "\d new_table"
```
